# Art direction

## Direction
Original angular comic-book silhouettes in a warm industrial wasteland: cobalt/teal machine steel, sun-bleached concrete, rust-orange accents, and small acid-lime power indicators. Broad shapes and restrained cel shading should read at a phone-sized battlefield. Use a consistent three-quarter side view with near/far limb occlusion and visible ground shadows.

## Rivet initial design spec
Adult human mechanic-fighter, athletic practical proportions (not chibi), oversized glove on the tool hand, asymmetrical copper-and-teal workshop jacket, reinforced boots, canvas tool belt, and a distinct crescent wrench-hammer hybrid. Friendly determined face, expressive eyebrows, protective goggles pushed onto the forehead. Front, side, three-quarter, and back turnarounds must retain the same master height and lighting from upper left.

## Production constraints
Create layered original source art, separate near/far limbs, hide overlaps beneath joints, and export transparent runtime parts on a shared master canvas. Rig notes must define pivots, draw order, sockets, hitboxes, and hurtboxes. No generated or placeholder artwork is represented as final approved art.
